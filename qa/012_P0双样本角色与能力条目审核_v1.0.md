# P0 双样本角色与能力条目审核 v1.0

审核对象：

- `worldbook/characters/P0/001_陈俊.md`
- `worldbook/abilities/P0/001_陈俊_能力.md`
- `worldbook/characters/P0/002_珊多拉·凯尔薇·尤拉西斯.md`
- `worldbook/abilities/P0/002_珊多拉·凯尔薇·尤拉西斯_能力.md`

目标：用 P0 前两名人物验证《希灵帝国》是否能严格复用“咩咩制卡·全栈”的人物 `chara-v1` 与独立能力绿灯结构；本轮通过后，后续 P0 才允许按同一母版批量生产。

## 一、格式审核

### 角色条目

两条均严格保持本项目冻结后的 `chara-v1` 字段顺序：

`名字 → 性别 → 印象 → 发色 → 发型 → 瞳色 → 身材 → 胸部 → 上衣 → 下装 → 配饰 → 鞋子 → 心理模型四项 → 三条对话范例`

未引入《三国无双姬》的“武道等级 / 标志性武器”等项目专属字段。

### 能力条目

两条均使用咩咩全栈能力绿灯母版：

```text
<核心设定:角色名·能力>
能力定位:...
核心能力:
- ...
法宝与武器:
- ...
战斗特点:...
限制与代价:
- ...
</核心设定:角色名·能力>
```

人物条目不展开技能树；能力条目不重复心理模型、完整外貌和日常关系。

结论：**PASS**。

## 二、具体数值与证据分级

### 陈俊

原著正文未给稳定基础发色、瞳色、数字身高与体重。

本轮为了满足最终注入条目必须具备具体数值的全栈规则，冻结以下【制卡合理估算】：

- 发色：黑色。
- 发型：自然中短发。
- 瞳色：深棕色。
- 身高：178cm。
- 体重：68kg。

这些值只属于本卡视觉与体态连续性设计，不得在 QA、说明文或对外表述中伪装成远瞳原著官方数据。

原著明确成立的能力/状态锚点包括：

- 开篇为高三学生。
- 早期已拥有异常强大的精神控制与跨时空精神连接能力。
- 碳基肉体会限制精神力继续增长，强行提高存在严重大脑损伤风险。
- 身体随后接受希灵技术强化。
- 后期能够将自身肉体完全虚空化；这一状态必须时间线限域。

## 三、外观变化与能力机制拆层

本轮采用固定原则：

- **角色条目写结果。** 例如珊多拉右半身变成黑焰、利爪约50cm；陈俊后期虚空化仍保留近似人形轮廓。
- **能力条目写原因和机制。** 例如深渊形态如何发动、精神控制如何作用、事项构成的成功率和反噬、虚空化为什么能维持意识。
- 变化不产生明确身高变化时，不凭空制造“变身后又长高几厘米”；已知总身高继续维持冻结值。
- 能量化、虚空化等使“常规体重”失去物理意义的形态，不强行伪造一个公斤数。

结论：**PASS**。

## 四、能力层原著边界

### 陈俊

能力条目当前只保留：

- 皇帝精神力。
- 精神控制 / 心灵干涉。
- 皇帝权限。
- 身体强化。
- 后期虚空操控 / 自身虚空化。
- 帝国资源调用边界。

特别保险：皇帝权限不等于全知、无限战斗力或“所有帝国设备都随叫随到”。早期肉体承载上限必须生效。

### 珊多拉

能力条目当前只保留：

- 夺灵者 / 灵魂攻击。
- 精神控制与大范围灵魂支配。
- 深渊形态 / 深渊格斗。
- 心灵瘟疫。
- 事项构成。
- 尤拉西斯皇权。
- 成对希灵军刺与帝国资源调用。

特别保险：

- “事项构成”不得解释成许愿术。原著早期明确成功率不足十分之一，且有严重反噬与因果崩溃风险。
- 深渊形态、心灵瘟疫、事项构成、尤拉西斯皇权必须服从实际剧情阶段。
- 尤拉西斯皇权不能写成无代价无限复活。

结论：**PASS**。

## 五、时间线与触发要求

1. 人物源码允许保存完整状态变化，但标记为后期的内容只有在时间线确认已经发生后才允许成为当前现实。
2. 最终装配时人物与能力条目的 regex / 关键词只扫描 `<story_scene>`；不得因为聊天历史曾出现人物名而长期常亮。
3. 能力绿灯除人物名外还应要求能力/战斗/对应状态语义，避免普通日常提到“陈俊”或“珊多拉”时整套能力百科一起注入。
4. 时间线优先于静态人物源码：早期陈俊不知道虚空生物本质；早期珊多拉也不能主动使用尚未真实解锁的后期荣耀机制。
