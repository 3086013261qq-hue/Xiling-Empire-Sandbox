# 《希灵帝国》P2 高频正式角色二次筛选与分层审核 v1.0

## 一、目的

P0～P1-F 已完成 51 名正式角色后，对整本《希灵帝国》进行第二轮人物补漏。重点解决两类历史问题：

1. 旧目录过度偏向“本体原创 / 帝国直属”，漏掉了大量真正长期反复出现的跨世界角色；
2. 单纯按名字频次会把高密度单篇章角色与真正跨卷常驻角色混在一起。

唯一原著源：`《希灵帝国》【精校】作者：远瞳.txt`。

## 二、方法

- 先用全文精确名字命中次数作为检索信号；
- 再核首次出场、末次出场、跨卷跨度、稳定身份、是否持续参与家庭/军务/宗教/文明事务；
- 最后按“世界书独占人物卡是否值得长期占用 token”决定正式化。

**命中次数不是唯一依据。** 例如“香草”既是角色名也是普通名词，原始次数存在污染；Rider/美杜莎也会与蛇怪种名混淆，因此此类角色必须靠上下文核定。
