## 一、修订后的总原则

角色是否来自外部作品，不决定其是否属于《希灵帝国》正式角色。

真正的判断标准是：

- 是否在《希灵帝国》正文中长期常驻；
- 是否已经进入陈俊第一家庭 / 帝国核心 / 长期行动队伍；
- 是否拥有稳定独立人格和反复出现的关系网；
- 是否在《希灵帝国》中形成大量新增经历、能力、装备、身体状态或身份变化；
- 是否需要在长期剧情中被模型稳定恢复，而不能只依赖原作人物百科。

满足以上条件者，一律制作完整人物条目 + 独立能力条目 + 时间线限域 + QA。

## 二、首批 P1-F 正式角色

45. **水银灯**
- 第一家庭长期正式成员。
- 陈俊多次以“女儿 / 家长”关系与其相处；正文明确形成“家里人出门必须带上水银灯”的长期生活规则。
- 高频贯穿多卷，并具有大量《希灵帝国》侧新增状态。
- 结论：**正式角色，不是桥接角色。**

46. **毒岛冴子**
- 正文明确“跟第一家庭呆了很长时间”。
- 长期参与跨世界行动与家庭生活。
- 结论：正式角色。

47. **佐天泪子**
- 在《希灵帝国》中获得希灵侧特殊能力与持续成长，原作静态资料不足以恢复其当前状态。
- 结论：正式角色。

48. **御坂10031（御坂妹妹代表）**
- 两万名御坂妹妹被帝国接管后形成长期群体关系。
- 采用“10031正式代表个体 + 妹妹群体关系”结构，不给两万名个体机械建卡。
- 结论：正式角色代表。

49. **吉尔妹 / 女性吉尔伽美什**
- 长期进入第一家庭生活，形成小泡泡贴身关系，并进入帝国附庸军语境。
- 结论：正式角色。

50. **八云蓝**
- 长期与第一家庭共同生活、出行，家庭关系与《希灵帝国》侧经历持续累积。
- 结论：正式角色。

51. **雪华绮晶**
- 在《希灵帝国》中形成陈俊精神海长期居留等根本性新状态。
- 结论：正式角色。

- 正式角色继续严格使用冻结的咩咩全栈“人物 + 能力”双层母版。
