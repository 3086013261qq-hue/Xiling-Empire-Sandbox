## 一、本轮修正规则

1. 第一卷因体量拆为“上 / 下”两个独立 `<world_timeline>` 块；**每个独立块均重新从事件A开始**。拆分不改变“第一卷”母卷编号，也不改变冻结的13卷结构。
2. 正式时间线中的每个固定事件必须给出确定的 `YYYY年MM月DD日`，禁止在事件日期字段继续使用“同日 / 数日后 / 具体日未明 / 约某日”等模糊值。
3. 原著写死的公历、节日、星期与“第二天 / 三天后 / 后天 / 明天”等相对时间为最高日期证据。
4. 原著没有唯一月日时，允许按全栈规范补造“制卡锚定日期”；该日期只服务于时间线连续推进，**不宣称是远瞳正文给出的官方月日**。
5. 维迪斯世界与地球时间流速明确不是1:1。第55～108章使用“维迪斯当地制卡锚定日”，保持当地相对日连续；第109章返回地球后重新切回地球公历。两套时钟禁止直接换算。
6. 每个独立时间线块末尾补齐“沙盒模式”事件，作为该块固定事件后的开放推进状态。

## 五、冲突与取舍记录

### 1. 第16章的“昨天攻击”冲突

同章同时存在：
- “这之后的几天”；
- “今天是难得的休息日”；
- 枪击案“约十天前”；
- 又称此前攻击者为“昨天攻击我们的”。

这些无法同时成立。为贯通第1～118章，采用能同时满足“几天后 / 休息日 / 约十天前 / 12月05日下一硬锚”的2010-12-04；“昨天攻击”视为早期文本局部时间口径不严，不据此破坏整段连续性。

### 2. 第27～35章的“第三天”与“约72小时”

第33章明确第三日，第27章又给出约72小时的跃迁恢复量级。故第33～34章锚定12-08第三日，第35章返程落在12-09，兼容“第三日内发生关键事件、约72小时后完成返程”。

### 3. 第46章“半个月后寒假”与春节硬锚

第46章是12-20的工程锚；其“还有半个月放寒假”只约束寒假临近，不用于反推春节日期。春节由2011年实际农历硬锚确定为2月3日，二者之间允许存在寒假期间的叙事留白。
