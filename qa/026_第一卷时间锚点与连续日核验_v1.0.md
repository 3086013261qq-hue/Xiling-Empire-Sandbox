## 1. 日期证据等级

### A｜正文硬锚
正文直接给出公历日期、节日/农历日、明确的“第二天/三日后/昨天/后天”等可闭环信息。

### B｜高置信重建
由多个A类证据互相校验后反推得出；正式时间线允许采用，但必须保留“据连续时间证据推定”的性质，不得伪装成正文逐字写出的公历日期。

### C｜区间锚
正文只给“几天后 / 半个月 / 前几天”等范围，无法唯一落到某一公历日。正式时间线必须保留区间，不得补造精确日期。

### X｜跨世界独立时钟
异世界当地时间与地球时间明确不是1:1。必须分开记录，不得拿当地“第二天/十几天”直接递增地球公历。

## 2. 第一组硬锚：2010年12月

### 2.1 第20～23章形成双重闭环

正文第20章明确：

- 许峰于 **2010年12月1日** 前往塔克拉玛干；
- “三日后”失踪；
- 当前叙事中浅浅说“前天”仍通过电话；林雪追问“昨天呢”；叙述明确“昨天”就是失踪日。

据通常连续日计算：

- 2010-12-01：出发；
- 2010-12-04：三日后，失踪；
- 2010-12-05：第19～21章当前日。

第22章开头又明确“第二天早上”，因此推进到 **2010-12-06**；第23章随即直接写出“于公元2010年12月6日……”，形成第二重校验。

冻结：

- 第19～21章：`2010年12月05日`（B级，高置信闭环）
- 第22～26章：`2010年12月06日`（A/B双锁；第23章公历日期正文直书）

### 2.2 第1～18章向前回推

第1章开场同时给出：

- “周一”；
- “已经初冬”。

第5章明确“第二天”；第7章浅浅说“你昨天怎么没来上课”；第11章明确当晚23:30；第12章进入午夜；第13章明确凌晨2:12；第14章早自习并回指“昨天发生的校园枪击案”。

第16章林雪回忆校园枪击案发生在“大约十天前”。结合12月5日前后的硬锚，2010年11月下旬的连续链与星期完全吻合，其中 **2010年11月22日为周一**。

因此冻结为高置信重建：

- 第1～4章：`2010年11月22日`（周一；B级）
- 第5～6章：`2010年11月23日`（“第二天”；B级）
- 第7～11章：`2010年11月24日`（校园枪击案日；B级）
- 第12～15章：`2010年11月25日`（午夜跨日后；B级）

第16～18章为林雪登门、异能组织揭示。正文只给“这之后的几天”“难得的休息日”以及枪击案“大约十天前”，不能把“大约十天”硬写成绝对十天。其最自然落点约在 **2010年12月04日前后**，但正式时间线应标为区间/推定，不升级为A类官方日期。

冻结：

- 第16～18章：`2010年12月上旬、12月05日前（约12月04日前后）`（C/B）

## 3. 第一次异世界段：第26～35章

第26章在2010-12-06的塔克拉玛干遗迹中发生意外传送。

第27章潘多拉明确：

- 空间跃迁系统距下一次启动还需72小时；
- 陈俊将其概括为“未来三天异界游”。

第29章明确“异世界，下午”；第33章明确“今天已经是我们来到这个……世界的第三天”；第34章末传送条件恢复并准备返程；第35章回到塔克拉玛干。

冻结口径：

- 第26章：地球出发锚 `2010年12月06日`
- 第27～34章：第一次异世界连续段，约72小时量级
- 第35章：回归约落在 `2010年12月09日前后`，属于B/C级推定，不得写成正文直书日期

注意：这一段虽可依据72小时建立连续时长，但正文没有给返程电子日期牌，因此正式成稿应保留“约/据72小时推定”的证据等级。

## 4. 珊多拉入学与欢迎宴会：第36～46章

第36章虽以“又是新的一天”开头，但同时说“自从我前几天从异世界回来之后”，因此**不能**机械地把第36章写成第35章翌日。

第36～40章为同一学校日的连续事件：

- 珊多拉转入班级；
- 校园冲突；
- 午饭；
- 下午课程；
- 班级得到“三天后晚上”欢迎仪式消息。

第41章明确“三天的时间转瞬即逝”，并发生于放假日的下午至晚间；第41～45章为同一欢迎宴会连续段；第46章开头明确“第二天”，且说“还有半个月的时间就要放寒假了”。

冻结：

- 第36～40章：同一日，但公历日未锁死（C级）
- 第41～45章：第36～40章之后三天，同一日宴会（C级）
- 第46章：宴会次日（C级）
- 第46章与春节之间存在明确时间跳跃，不得以章节相邻伪造成连续次日

第45章“一个月前已经向平静生活道别过一次”可作为约束欢迎宴会大致位于12月5之后约一个月量级的软证据，但不足以唯一确定公历日。

## 5. 春节硬锚：第47～54章

第47章明确“大年三十”，并推进到“年三十晚上十二点”；第48章明确“大年初一凌晨零点”。

由于上一组硬锚仍处于2010年12月，故这里是下一次春节，即2011年春节。按公历换算：

- 2011年02月02日：除夕 / 大年三十
- 2011年02月03日：大年初一

该公历换算属于“历法换算”，不是正文逐字写出的公历日期，正式时间线应注明其推导性质。

第48～53章前半连续发生在大年初一凌晨，回家时“凌晨一点多钟”。第53章随后明确“后天就要出去旅游”，并直接跳转到撒哈拉旅行现场。

因此冻结：

- 第47章：`2011年02月02日` 夜 ～ `2011年02月03日` 00:00（历法换算）
- 第48～53章前半：`2011年02月03日` 凌晨（历法换算）
- 第53章后半～55章：`2011年02月05日` 撒哈拉旅行与第二次跨世界出发（由“后天”＋历法换算得到，B级）

## 6. 维迪斯段必须使用“双时钟”

### 6.1 禁止把维迪斯当地日直接换算成地球公历日

第55章后进入维迪斯。

正文随后明确出现大量当地连续时间：

- 第69章：基地初建，当晚多人彻夜不眠；末尾推进到“第二天一大早”；
- 第71章：希灵主机启动后的“第三天下午”基础建筑完工；
- 第80章：明确“在之后的几天中”；
- 第82章：明确“第二天早晨”；
- 第84章：主机复制完成，并明确前哨基地建立至此“不过十几天过去”；
- 第85章：再次明确“在之后的几天中”；
- 第87章：再推进到“第二天早上”；
- 第89章：敌军“四天后”抵边境，实力展示定在“后天中午”；
- 第93～97章：由“明天中午 / 明天傍晚”锁住展示与决斗的连续日；
- 第99～100章：由“明天”推进至大战；
- 第107章：大战后当夜；
- 第108章：回指“昨天晚上”，并在收尾阶段明确“我们在维迪斯又逗留了三天”。

这些证据证明：维迪斯当地经历显著超过十余日，且含多个“几天”跳跃。

### 6.2 地球却只过去三天

第109章回到地球，正文明确：

- 回归时为傍晚；
- 潘多拉准备计算日期；
- 小泡泡直接指出电子日期牌；
- 陈俊确认“原来时间已经过去三天了”。

因此第二次跨世界段必须冻结为：

- 地球出发：`2011年02月05日`
- 维迪斯当地：独立连续时钟，跨度显著超过十余当地日，具体“几天”处不得擅自数字化
- 地球回归：`2011年02月08日` 傍晚（由出发锚＋地球过去三天推定）

### 6.3 正式时间线书写规则

维迪斯段不能写成：

`2011-02-05 → 02-06 → 02-07 → ……` 按当地日一路递增。

推荐正式结构：

- 外层保留地球锚：`2011年02月05日～2011年02月08日（地球计时）`
- 内层事件注明：`维迪斯当地第1日 / 次日 / 主机启动后第3日下午 / 数日后 / 十几日后 / 再数日后 / 大战前日 / 大战日 / 战后三日收尾`
- 对正文只说“几天”的位置，继续写“数日后”，不虚构第N日

这样既服从“YYYY年MM月DD日 + A/B/C编号”的总格式，又不制造错误的一比一世界时间。
