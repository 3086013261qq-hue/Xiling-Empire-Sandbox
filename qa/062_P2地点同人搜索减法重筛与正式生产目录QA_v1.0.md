## 一、重筛目的

P2原目录建立于“尽量覆盖高频子地点”的阶段，其中混入了四类不应继续独立生产的内容：

1. 可由咩咩同人搜索可靠补全的外部作品普通地点；
2. 已经能由P0/P1父地点完整承载、无需独立 `当前位置:` 触发的子区域；
3. 在多个世界反复出现的设施/舰种/结构类别；
4. 只服务单次剧情、没有持续空间身份的临时场景。

本轮不以“出现次数”作为独立成卡的充分条件，而以运行时价值为准：

- 是否能形成稳定独立场景；
- 是否需要独立当前位置触发；
- 是否承载《希灵帝国》专属历史/状态；
- 是否存在父地点无法安全替代的信息；
- 是否会因同人搜索而产生重复百科或冲突。

`P2 RE-SCREEN PRINCIPLE: PASS`

## 二、旧23项主候选逐项裁决

### 1. 第二中学 -> KEEP，正式目录名改为“K市第二中学”

原著开篇即明确陈俊就读于K市第二中学，与街对面的沧澜私立高中形成长期日常对照；第38章还给出四大楼区、宿舍区、校园中央设施等稳定空间结构。它并非外部作品地点，而是《希灵帝国》自己的长期日常场景。

裁决：

`KEEP AS P2: K市第二中学`

### 2. 沧澜私立高中 -> MERGE

沧澜私立高中主要作为第二中学街对面的贵族学校、早期事件舞台和社会对照存在；没有形成与K市第二中学同等级的长期独立运行场景。

裁决：

`MERGE INTO K市 / K市第二中学 CONTEXT`

### 3～5. 奎尔萨拉斯 / 暴风城 / 幽暗城 -> DELEGATE TO FANDOM SEARCH

三者均为艾泽拉斯原作地点。《希灵帝国》确实在这些区域发生过联络、外交、战斗和调查，但其常规地理、城市结构与社会生态均属于原作知识；本卡P1《艾泽拉斯》已经负责希灵介入后的世界状态。

裁决：

`NO P2 CARD / FANDOM SEARCH + P1 艾泽拉斯`

### 6. 妖怪山 -> DELEGATE TO FANDOM SEARCH

妖怪山是幻想乡原作地点。书中虽发生空中大陆坠落等异常，但该变化属于P1《幻想乡》需要锁定的希灵改写层；妖怪山本身的常规地理不重复制作。

裁决：

`NO P2 CARD / FANDOM SEARCH + P1 幻想乡`

### 7. 妖怪镇 -> KEEP

妖怪镇并不是东方原作地图中的普通地点，而是《希灵帝国》跨世界人口进入阿瓦隆后形成的稳定聚居空间。它后来成为正式集会活动地点，红魔馆也整体迁入妖怪镇，原因包括当地能量场对芙兰朵露状态的影响。

裁决：

`KEEP AS P2: 妖怪镇`

### 8. 生态穹顶 -> EXCLUDE GENERIC CLASS

原著中“生态穹顶”出现在不同星球和工程计划中，例如御坂学生社团建造的大型生态工程、火星避难所相关设施等。它不是一个唯一坐标或唯一建筑。

裁决：

`EXCLUDE: REPEATED FACILITY CLASS`

### 9. 星球要塞 -> EXCLUDE GENERIC CLASS

“星球要塞”是帝国星体级军事单位/设施类别，维斯卡壁垒星、天神锻炉等具体对象各有独立身份。若建立泛称地点，会把多个完全不同实体错误合并。

裁决：

`EXCLUDE: SHIP / FORTRESS CLASS`

### 10. 文献馆 -> KEEP

文献馆是旧帝国“圣堂”体系中的具体巨型设施，拥有明确实体结构、复杂内部通道、数据库/运算功能和首领蜂防御体系，并承担希尔维亚、首领蜂等关键剧情。它不是泛称图书馆。

裁决：

`KEEP AS P2: 文献馆`

### 11. 森图 -> KEEP

森图/森图港是母大陆上历史悠久的“失落世界接驳港”城市，城市本身拥有稳定社会空间、中央广场、探险者文化和长期交通功能，是失落世界体系的重要现实侧入口。

裁决：

`KEEP AS P2: 森图`

### 12. 古代花园 -> MERGE INTO 失落世界群

古代花园是独特碎片世界，拥有破碎星体草原、小型封闭宇宙等奇观，也为识别母星碎片来源提供过线索。但它后期主要是低危险中转/风景区域，没有独立长期帝国管理状态。

P1《失落世界群》已明确承载此类碎片世界的周期交汇、碎片来源和运行规则，并明确“普通子世界若只提供原生风景而没有独立希灵状态，不必全部拆卡”。

裁决：

`MERGE INTO P1 失落世界群`

### 13. 古代城 -> MERGE INTO 失落世界群

古代城主要承担一次重要探险、半龙人初遇和遗迹战斗，没有形成后续稳定管理/迁移/归属状态。

裁决：

`MERGE INTO P1 失落世界群`

### 14. 悬空河 -> MERGE INTO 失落世界群

悬空河拥有极强视觉辨识度：数百公里长悬空河道、破碎河岸、约36公里高度的闭合循环空间，也是通往天空之塔的路线节点；其地貌还帮助确认失落世界与盖亚母星碎片的关系。

但这些信息仍属于失落世界碎片网络的原生奇观与交通逻辑，缺乏独立长期帝国状态。P1《失落世界群》可安全承载。

裁决：

`MERGE INTO P1 失落世界群`

### 15. 天空之塔 -> KEEP

天空之塔不是普通奇观碎片，而是十五天区神秘侧母星系统的关键旧帝国设施，涉及冈达巨像控制、母星系统、旧首府真相和后续回收链；它拥有独立进入路线、长期守卫体系与关键时间状态。

裁决：

`KEEP AS P2: 天空之塔`

### 16. 巨龙王国 -> KEEP

巨龙王国是与母大陆隔离的稳定龙族领地，拥有独立社会、使节体系、守护职责，并作为通往遗忘花园的重要父级场景之一。它属于《希灵帝国》原创世界结构，不可交给外部同人搜索。

裁决：

`KEEP AS P2: 巨龙王国`

### 17. 松林村 -> MERGE INTO 海森伍德

松林村是海森伍德终焉篇的重要初遇村落，但本质仍是该行星上的普通村庄。P1《海森伍德》已经明确普通村镇若无需独立当前位置，不机械拆卡。

裁决：

`MERGE INTO P1 海森伍德`

### 18. 北要塞 -> MERGE INTO 海森伍德

北要塞是黯月战争前线的军事据点，承担征兵、前线战局和调查场景，但属于海森伍德战争阶段的子地点，缺乏跨阶段独立状态。

裁决：

`MERGE INTO P1 海森伍德 WARTIME STATE`

### 19. 双子星传送站 -> KEEP

双子星传送站是第一季文明在海森伍德与瑞德穆恩两端建立的一对大型物质传送设施，具备自我修复、长期能源系统和跨星球交通功能；后世大量地表传送塔还是对其技术的仿制。

它不是普通中转点，而是双子星文明结构与战争历史的核心实体系统。

裁决：

`KEEP AS ONE PAIRED P2 LOCATION: 双子星传送站`

### 20. 生命神殿 -> MERGE INTO 世界树

原著明确生命神殿/生命之树核心殿堂属于世界树内部神殿区，是叮当与莉莉娜长期活动的核心空间，但其物理身份不能与世界树本体割裂。

裁决：

`MERGE INTO P2 世界树 / NO SEPARATE CARD`

### 21. 世界树 -> KEEP

世界树既是叮当的神殿，也是世界管理终端和巨大空间结构；其影子空间投影半径可达上百公里，本体还通过空间夹缝扩展。它长期承载生命神殿、世界管理、造物实验和跨世界干预，是稳定高频的希灵原创/神族设施。

裁决：

`KEEP AS P2: 世界树（BODY INCLUDES 生命神殿）`

### 22. 边境世界 -> EXCLUDE GENERIC / PLURAL

“边境世界”在原著中多为多个边境科研世界、前线世界的类别称呼，并非一个唯一地点。

裁决：

`EXCLUDE: GENERIC / PLURAL WORLD CLASS`

### 23. 遗忘花园 -> KEEP

遗忘花园是十五天区神秘侧旧帝国稳定设施/城市，拥有巨龙守卫、独立入口权限、长期概念层隐藏状态；奥蕾莉亚苏醒后重新开放，天使之城后来释放在其上空约17公里处。其空间身份与天使之城明确分离。

裁决：

`KEEP AS P2: 遗忘花园`

## 三、二次筛选池4项裁决

### 1. 影子要塞 -> MERGE

影子要塞是影子空间/影子城军政核心区域语境，控制母巢等设施位于其中；P0《影子空间》《影子城》已经承担其父级空间和军事行政状态。

`MERGE INTO P0 影子空间 / 影子城`

### 2. 世界管理中心 -> EXCLUDE

“世界管理中心”至少存在两种混杂语境：神族世界管理体系，以及陈俊早期联络艾泽拉斯时为了唬人临时冒用的“世界管理中心”名号。字符串本身不能安全映射为一个唯一物理地点。

`EXCLUDE: AMBIGUOUS / INSTITUTIONAL / FAKE-TITLE USAGE`

### 3. 远疆小行星基地 -> MERGE

远疆航线中的小行星研究基地由塔维尔团队短期快速搭建，服务特定研究阶段，属于P1《远疆》的临时科研节点。

`MERGE INTO P1 远疆`

### 4. 故乡世界太古深渊之门 -> MERGE

该特定大门拥有重要终焉历史，但P0《故乡世界》已经明确承载其存在、位置和架桥关系；当前无需独立 `当前位置:`。

`MERGE INTO P0 故乡世界`

## 四、高频希灵原创地点漏项扫描

重筛不能只做减法，否则会重复出现“陈俊家式漏项”。本轮额外扫描高频希灵原创稳定场景。

### 新增1：帝国高等军事学院

原著长期反复出现的影子城教育设施，御坂妹妹与多个世界选拔的学生在此就读；师资包括帝国教官、异世界英雄与英灵等。它拥有明确长期社会功能、稳定场景身份，并非外部作品原作学校。

正式目录名：

`帝国高等军事学院`

### 新增2：次元枢纽

影子城在穿越者事件后保留并正式发展出的跨世界民用交通设施。它承担穿越者返回、访客审批、跨世界人员流动，并成为“宏世界”民间互联网络的重要物理枢纽。

正式目录名：

`次元枢纽`

### 已检查但不新增

- `将军城`：帝国上将号展开后的部署形态，P0《帝国上将号》已经承载，不另拆；
- 泛称“研究所/研究中心”：对应多个不同世界和临时机构，不统一成地点；
- 学园都市的宗城研究所等短期基地：由P1《学园都市》承载希灵介入状态，不扩大P2；
- 影子城普通商业街、广场、旅馆、舰内舱室：不机械拆卡。

## 六、父子层级与关键词安全锁
