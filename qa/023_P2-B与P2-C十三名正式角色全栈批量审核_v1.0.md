## 四、时间线与篇章隔离

1. **P2-B 72～74**：仅在梅洛瓦奴役世界或瑞德穆恩—海森伍德相应篇章语义中高强度触发；不得因为角色名偶然出现而把整段篇章秘密注入普通场景。PASS。
2. **阿奴丽丽**：反抗组织身份、神经毒剂真相与隐藏传送设备都属于梅洛瓦篇章信息；初见前不得泄漏。PASS。
3. **图拉佐**：旧帝国仆从军经历、叛国历史、与巴瑞安决裂及反抗组织首领身份按剧情揭示顺序推进。PASS。
4. **索娅**：上古四英雄、双子星传送站、循环协议与深渊污染均严格绑定对应篇章。PASS。
5. **库丘林 / 红A / 美狄亚 / 海格力斯**：冬木阶段仍处原英灵/Master体系；阿瓦隆长期生活、幽能英灵化和帝国军事学院工作仅在后期解锁。PASS。
6. **魔理沙 / 幽幽子**：作为幻想乡正式人物保留独立人格与危机功能，但不自动写成帝国编制人员。PASS。
7. **凯瑞甘**：人类幽灵特工历史、刀锋女王状态、受“启示”趋势控制、重新接管虫群等按克普鲁线推进。PASS。
8. **夏娜 / C.C.**：第一代审查官身份必须在时空管理局正式建立后生效；夏娜初次跨界时与阿拉斯托尔失联的状态不得被后期权限覆盖。PASS。

## 五、能力边界检查

- 阿奴丽丽不是神经毒剂免疫者；其清醒依赖剂量控制、反抗组织知识与潜伏。PASS。
- 图拉佐的梅洛瓦强化体质明显强于凡人，但远低于真正希灵使徒；正文也明确其军事天赋不如巴瑞安。PASS。
- 索娅龙威是生命位格型威压，对更高生命阶梯无效；龙类身体控制不等于不死。PASS。
- 英灵组保留正文实装的枪术、投影、魔术、狂化等核心定位，不写成对希灵/神族规则绝对必杀或绝对无效。PASS。
- 魔理沙与幽幽子只保留《希灵帝国》正文需要的幻想乡能力定位，不搬入完整外部弹幕技能表。PASS。
- 凯瑞甘“虫群资源”与“个人肉体/精神战力”明确分离；虫群可能产生脱离其控制的新节点。PASS。
- 泰克斯仍是凡人人类重装战士，动力甲不升级为希灵装备。PASS。
- 夏娜与 C.C. 的管理局权限属于基层审查节点；热点扫描、跨位面传送和支援依赖管理局网络，不等于个人固有军权。PASS。
- 对外部作品角色，禁止使用外部百科补齐《希灵帝国》正文未实际展开的整套能力树。PASS。

## 六、职责与格式

- 人物层负责身份、外观、体型、心理模型、稳定关系与说话风格。
- 能力层负责能力机制、装备、战斗方式、限制、代价与阶段变化。
- 未使用游戏化技能面板、伤害数字、等级表或冷却栏。
- 成年人形女性冻结具体 cm / kg / 罩杯并标来源；未成年/年轻少女不设置成人罩杯；异种形态按真实生命结构处理。
- 最终触发仍只扫描 `<story_scene>`，时间线事实优先于静态条目。
