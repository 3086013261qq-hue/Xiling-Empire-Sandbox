## 二、关键来源锚点与冻结结论

### 40｜盖亚
- 【原著正文明示】世界仲裁机关二号机；后期确认全称“分布阵列式希灵主机母体机-盖亚型”，为原型机和唯一投入使用个体。
- 【原著正文明示】旧实体录像：淡紫色美丽长发、淡紫色明亮眼睛、白色长裙。
- 【原著正文明示】灵魂改造事故后身体从概念层面被摧毁，当前以母星为载体，蓝色投影只是交互外观。
- 【制卡合理估算】人形等效 168cm / 53kg / C；当前投影无真实物质质量。
- PASS：角色层区分旧实体 / 当前投影 / 母星意识；能力层不把投影当肉身。

### 41｜维嘉-0001
- 【原著正文明示】漂亮、剽悍的女性上半身 + 机械蝎形下半身；六条机械节肢；尾长约3m；自重“起码两吨”。
- 【原著正文明示】编号维嘉-0001；接受陈俊直接命令。
- 【原著正文明示】装甲蝎坚持近战格斗，使用双刀；尾部具高威力光子加农炮/狙击晶体；具高速机动和战场扫描能力。
- 【制卡合理估算】总高 250cm / 冻结体重 2100kg / 女性上半身 C；发色瞳色为制卡估算。
- PASS：未人类化抹掉蝎形机体；未把远程炮写成其唯一战斗方式。

### 42｜西卡罗
- 【原著正文明示】骑士脸大叔、一脸正气、表情坚毅；地球潜伏常穿黑超/黑客帝国式打扮。
- 【原著正文明示】帝国军官，擅长阵地防御战，本身战斗力不容忽视。
- 【原著正文跨段确认】在连续骚扰与拦截战中依靠指挥天赋与使徒能力，使己方保持极低乃至零损失并多次全歼来敌。
- 【制卡合理估算】186cm / 84kg。
- PASS：搞笑摆摊属性没有覆盖军事本职；能力层未虚构命名“防御神技”。

### 43｜菲娜
- 【原著正文明示】稻黄色长发、灰蓝色瞳孔；早期坐于王座、身体连接大量电缆和管线。
- 【原著正文明示】原为人类，在战争中仅余大脑，后融合希灵使徒躯体，以此控制女王舰队。
- 【原著正文明示】战争结束后因灵魂已无法适应普通人类生命形式，被整体转移进全新的希灵使徒身体；后期穿简朴灰白色长裙。
- 【制卡合理估算】168cm / 52kg / C。
- PASS：早期半机械女王、后期完整新身体严格时间线分层。

### 44｜麦迪雯
- 【原著正文明示】雌性乌鸦；命名“麦迪雯”；初期约一尺长，数日后成长到比普通乌鸦大一半。
- 【原著正文明示】严重散光；奥术凝视存在聚焦问题；可释放奥术 + 电浆混合暗影箭；不依赖普通进食，可汲取环境能量。
- 【原著正文明示】被视为未来希灵神系最早一批神明 / 乌鸦之神候选，但当前仍是幼年成长个体。
