## 一、日期口径

本卷继续执行咩咩制卡包·全栈硬规则：

1. 正式 `<world_timeline>` 中每个固定事件必须写完整 `YYYY年MM月DD日`。
2. 原著没有官方公历月日时，使用“制卡锚定日期”；这只是世界书工程排序坐标，不是远瞳官方年表。
3. 跨世界不能默认1:1流速。莫布拉多、废墟世界分别使用独立当地制卡时钟。
4. 原著明确“第二天 / 第三天 / 四十八小时 / 二十四小时 / 一个多月”等相对证据优先于纯粹猜测。
5. 若正文季节词与已封版工程公历发生冲突，不篡改原文，也不偷偷回滚前卷；冲突必须在本QA显式保留。

## 三、第一处季节冲突：寒假 / 冬季 vs 继承工程公历

第761章明确写“现在还是寒假期间”。
第838章明确写“冬季已经快要走到尾巴尖上”。
第839章两次以“冬日阳光 / 冬日午后”描述环境。

但第六卷已经按前序“七十三天 + 半个月倒计时 + 十五天狂欢节 + 神界近十天”等连续证据封版到2013年04月30日，本卷第752章又明确是神界返回第三天。若现在为了“寒假/冬日”把第七卷整体倒推到1～2月，会直接破坏已经冻结的前六卷日序。

因此冻结处理：

- 保留原著季节词，**不修改文本事实**；
- 正式时间线继续继承前卷工程公历；
- 将“寒假 / 冬季尾声 / 冬日午后”标记为**源文季节措辞与工程公历冲突**；
- 不把2013年05～06月声称为作者官方月份；
- 后续若用户专门授权全书公历重构，可统一回头处理；当前时间线生产阶段不回改封版卷。

这与第六卷QA036对“冬日清晨/零下五度”的处理原则一致。
