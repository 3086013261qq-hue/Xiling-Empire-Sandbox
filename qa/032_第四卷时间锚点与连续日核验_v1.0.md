## 一、本卷时钟结构

第四卷存在四个需要区分的时间坐标：

1. **家乡地球时钟（第402～405章）**：第三卷第401章只确认“回到影子城”，未给家乡世界公历，因此第四卷重新建立工程锚。
2. **克普鲁当地时钟（第406～445章）**：远征进入另一个世界后按当地“第三天 / 三天 / 四天 / 数日 / 一个月零十天 / 还有一天”等相对证据连续推进。
3. **家乡地球时钟（第446～469章）**：克普鲁返航后重新建立家乡工程锚；第447章“事件结束两周后”、第448章“春末”、第450章“持续半个月的长假”等形成闭环。
4. **学园都市当地→冬木当地（第470～511章）**：第470章先短暂切回学园都市当地；第471章起进入冬木，另启独立冬木制卡时钟。冬木正文未给官方公历，月日只用于世界书连续性，不作为原作官方年表。

不同世界的日期数值**只用于各自内部顺序**。除正文明确说明相对流速外，不得拿两个世界的日期差直接换算时间倍率。

### 冬木当地制卡锚

冬木段没有正文官方公历。制卡锚选择从 **2012年11月04日** 开始，理由：

- 第511章明确“落叶”“寒风萧瑟”，适合晚秋/初冬。
- 第475、488等仍有正常学校日。
- 若11月4日为落地日，则：
  - 11月5日 = 周一；
  - 11月6日 = 周二；
  - 11月7日 = 周三；
  - 11月8日 = 周四；
  - **11月9日 = 周五**，恰好容纳第488章“今天早上远坂上学之前”的学校日；
  - 后续大战可自然跨入周末。
- 因此比把第488章锚到周六更符合正文学校日语义。
