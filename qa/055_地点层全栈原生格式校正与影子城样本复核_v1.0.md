## 一、校正原因

054完成了影子城的原著证据链、层级关系和时间状态核验，但其首版地点正文采用了项目自造的：

- `<影子城location>` 根标签；
- `<身份>`、`<空间与环境>`、`<时间状态锁>` 等内部子标签。

这些结构虽然便于工程审计，却不是《咩咩制卡·全栈》原生地点正文格式，因此不能作为正式装卡模板继续扩散。

本轮重新对照已保存的全栈格式规范：

- `00_狐妖小红娘_全栈1.0.0条目格式规范_v1.3.md`
- `WORLDBOOK_ASSEMBLY_v1.0_QA.md`

确认原生地点运行正文应为：

```text
<地点:名称>
介绍:...
</地点:名称>
```

地点属于独立世界书类别，最终装配位于地点分区（order 100~1），采用触发型 after_char 条目，并优先通过 `<status>` 中 `当前位置:` 精确触发。

`NATIVE FORMAT CHECK: PASS`

## 二、拆分粒度校正

影子城继续保持 **1个地点 = 1个正式地点条目**。

不把以下内容拆成独立世界书小条目：

- 空间环境；
- 出入交通；
- 居民与管理；
- 稳定功能；
- 第51～1613章期间的阶段状态；
- 正面/背面结构；
- 次元枢纽、访客区、普通商业街等尚未通过P2独立性审查的内部区域。

上述内容全部作为同一个 `<地点:影子城>` 的 `介绍:` 内容存在。

只有某个内部地点满足以下条件之一时，未来才允许单独建条：

1. 可独立、反复支撑完整场景；
2. 需要独立 `当前位置:` 值触发；
3. 拥有稳定且明显不同于父地点的空间/规则身份；
4. 已通过P2二次筛选。

`GRANULARITY: PASS / SHADOW CITY = ONE LOCATION ENTRY`
