## 三、P0级时间线检查

1. **纱姬娜 / 索娜**：初遇阶段正文明确“不会魔法”；神术与龙语魔法只在琳承认、赐福半龙人后解锁。PASS。
2. **阿尔忒弥斯**：奥林匹斯幕后者时期与后期阿瓦隆/女神教民政身份隔离；早期不泄漏后续转变。PASS。
3. **Rider / 佐佐木 / Saber**：冬木阶段仍受原英灵体系约束；阿瓦隆长期世界守护者身份仅在转化后生效。PASS。
4. **香草**：早期普通山地少女→鸦神核心信徒/神职者→未来教皇，三段强隔离；“未来教皇”不得提前成为当前现实。PASS。
5. **罗兰盖尔**：文明共同体领袖与后期帝国仆从军高级指挥身份按时间线推进。PASS。
6. **希尔瓦娜斯 / 吉安娜 / 雷诺 / 泽拉图**：文明领导权与帝国盟友关系不等于希灵权限。PASS。

## 四、能力边界检查

- 丁玲声波可破坏常规坦克，但不上推帝国主力单位级。PASS。
- 林风是压缩空气/风刃，不扩写天气权能。PASS。
- 八云紫“操纵境界”保留正文理论描述，同时明确实际能量上限。PASS。
- 御坂美琴电磁能力不能默认破解帝国设备。PASS。
- 吉安娜跨世界精神通信只证明精神信号强度，不等于实体跨虚空传送。PASS。
- 泽拉图永久匿踪不是对帝国/神族探测绝对隐形。PASS。
- 菲丽丝、罗兰盖尔、雷诺等文明型角色明确区分“个人能力”与“所属文明/舰队资源”。PASS。
