## 一、正式角色判定

1. 以《希灵帝国》正文中的实际人物地位、持续关系与剧情功能为准，不以是否本体原创判断。
2. 第一家庭、帝国核心、阿瓦隆/时空管理局、宏世界文明领导层、稳定盟友和单篇章不可替代人物均可正式收录。
3. 正式人物统一制作：人物条目 + 能力条目 + 时间线门槛 + QA。
4. 只是短期客串 / 少量增量者才使用 X-bridges。

## 二、职责与数值

- 人物层：身份、外观、体型、心理模型、稳定关系、对话风格。
- 能力层：来源、机制、作用范围、装备、战斗方式、限制、代价与成长阶段。
- 成年人形女性冻结唯一 cm / kg / 罩杯；正文无数值则标【制卡合理估算】。
- 未成年/儿童人物不设置成人罩杯；非人形、精神体、投影与异种按真实生命形态记录。
- 最终人物/能力只扫描 `<story_scene>`；时间线事实优先。
