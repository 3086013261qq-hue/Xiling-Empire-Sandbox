## 一、正式角色判定

1. 是否为正式角色，以《希灵帝国》正文中的实际人物地位、持续关系与剧情功能为准，不以“是否本体原创”判断。
2. 本体原创，以及来自外部作品但长期进入第一家庭、帝国核心、阿瓦隆/时空管理局编制、宏世界文明领导层或稳定行动圈的角色，都可制作正式完整人物卡。
3. 单一大篇章人物若塑造完整、独立因果强、对篇章不可替代，也可进入正式人物层，但必须强化篇章限域。
4. 只是短期客串 / 少量增量者才使用 X-bridges；桥接不是外部角色的默认归宿。
5. 正式人物统一制作：人物条目 + 能力条目 + 时间线门槛 + QA。

## 二、全栈职责与数值规则

- 角色条目：身份、外观、具体体型、服装、心理模型、稳定关系、对话风格。
- 能力条目：来源、触发、机制、作用范围、装备、战斗方式、限制、代价、成长阶段。
- 人形女性必须冻结唯一 cm / kg / 罩杯；正文无数值则在 QA 标【制卡合理估算】。
- 非人形动物、纯精神体、投影/星球意识按真实生命形态记录，不虚构不存在的生物学结构。
- 最终人物与能力只扫描 `<story_scene>`；时间线事实优先。
