## 一、正式角色判定

1. 是否为正式角色，以《希灵帝国》正文中的长期实际地位为准，不以“是否本体原创”判断。
2. 本体原创角色，以及来自外部作品但长期进入陈俊第一家庭、帝国核心或稳定行动队伍的角色，都可进入正式完整人物层。
3. 只是短期客串 / 单世界盟友 / 少量希灵侧新增状态者，不机械复制原作百科；优先时间线、阵营或轻量增量桥。
4. 已长期常驻的外部角色必须制作：完整人物条目 + 独立能力条目 + 时间线限域 + QA。

## 二、咩咩全栈职责边界

角色条目固定 XML-like 母版，负责：身份、外观、具体体型、服装、心理模型、稳定关系、对话风格。

能力条目负责：能力来源、触发、机制、作用范围、装备、战斗方式、限制、代价、成长阶段。

一句话：**角色回答“她是谁、现在长什么样”；能力回答“为什么能做到、怎样做到、能做到多远”。**

最终人物与能力均只扫描 `<story_scene>`；后期事实必须继续服从时间线。

## 三、数值规则

- 人形女性：必须冻结唯一身高 cm / 体重 kg / 罩杯字母；原著明示优先，无数值则标【制卡合理估算】。
- 男性：至少冻结身高 / 体重与稳定体态。
- 非人形动物、纯精神体、投影/星球意识：仍给可识别的具体尺寸或人形等效参数，但不虚构物种不存在的生物学结构；真实无质量状态必须明确标注。
- 变身/重塑后的外观结果归角色层，发动机制归能力层。
