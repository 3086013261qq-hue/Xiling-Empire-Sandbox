# 《希灵帝国》人物层目录与收录规则 v1.1

> 状态：人物目录骨架已建立；P0 原著锚点核对完成后进入逐人施工准备。
> 基线：设定层总审计完成后的 main。

本目录决定“哪些人物需要进入《希灵帝国》本体世界书、优先级如何，以及角色条目 / 能力条目如何按咩咩制卡包·全栈职责分层”。

## 一、收录原则

1. **只收《希灵帝国》本体原创人物与必须由本体世界书维护的身份变化。**
2. 外部作品人物不制作完整人物卡；其原作外貌、性格、能力、关系与原作历史交给咩咩预设同人搜索恢复。
3. 外部作品人物在《希灵帝国》中新增的帝国身份、特殊改造、当前阵营或重大剧情变化，只在必要时写“希灵侧增量状态”，不复制外部原作人物百科。
4. 人物卡不承担能力百科。人物条目写身份、外观、人格、关系、行为逻辑与能力概览；复杂能力另进能力层。
5. 任何后期人物、未来人物、隐藏身份与阵营变化都由时间线控制，不因人物条目存在而让早期角色提前知道。
6. 女性人物最终角色条目必须给出**唯一、具体的身高 cm / 体重 kg / 罩杯字母值**。原著明示优先；原著没有明确数值时，必须依据正文体型、年龄外观、比例与同角色长期稳定描写给出【制卡合理估算】。最终注入条目不得使用“未知 / 待定 / 约某范围”代替必填数值，也不得把估算伪装成原著事实。
7. 原著存在多个冲突数值时，原著核对/QA文件完整保存冲突；最终角色条目选择一个最符合连续正文与稳定后期口径的**制卡冻结值**，避免把互相冲突的多个数字同时注入模型。
8. 同一人物若存在成长、变身、合体、重塑等导致身高、体重、胸部、发色、发型、瞳色或服装变化的状态：**变化后的外观结果写在角色条目里；变化的发动方式、机制、强度、限制和战斗效果写入能力条目。**
9. 同一存在的不同形态/人格优先判断是否需要“单条多状态”而不是机械拆成两个人物；真正独立人格、独立因果与长期独立行动者则分条处理。

## 二、咩咩全栈人物 / 能力职责边界

### 角色条目

最终角色条目继续使用固定 XML-like 格式：

```text
<【人物名】character>
名字:
性别:
印象:
发色:
发型:
瞳色:
身材:【身高cm,体重kg,体态描述】
胸部:【女性罩杯；男性胸肌/平坦度】
上衣:
下装:
配饰:
鞋子:

心理模型:

- Trauma:
- Defense:
- Trigger:
- Need:

对话范例:
“”
“”
“”
</【人物名】character>
```

角色条目负责：

- 正式姓名、性别、稳定身份与当前阵营。
- 发色、发型、瞳色、具体身高、具体体重、具体罩杯/胸部状态。
- 常态服装与标志性配饰。
- 若存在明确外观变化，在对应字段内用简洁状态标记记录**变化后的结果**，但不在这里解释能力原理。
- 人格、心理模型、稳定关系与对话风格。
- 只保留能力名称/一句话概览，不写完整机制百科。

### 能力条目

能力条目独立承担：

- 能力名称、来源、触发条件、发动方式。
- 机制、作用范围、强度、限制、消耗、反制与成长阶段。
- 战斗装备、特殊形态、荣耀形态、合体、变身等技术/能力实现逻辑。
- 若能力会改变外貌，只说明“触发角色条目中的某状态”，不重复整套身材和服装描写。

一句话边界：**角色条目回答“她现在看起来是什么样、是什么人”；能力条目回答“她为什么能做到、怎样做到、能做到什么程度”。**

最终角色触发仍只扫描：`<story_scene>`。

- **林风**｜地球侧重要超自然体系人物
- **丁玲**｜地球侧重要超自然体系人物
- **卡门-3575**｜早期复仇军 / 希灵战士代表
- **菲丽丝**｜菲雅利文明重要人物
- **大族长**｜树精灵线重要人物（需复核正式姓名/称谓）
- **库瓦因**｜如神族家庭线需要独立触发，则由 P1-B 候选上调
- **艾莎莉**｜同上
- **阿尔忒弥斯**｜如神界—帝国通道、生命神殿剧情需要独立触发，则上调
- 其他只在单卷或单世界短期出现的本体原创人物：待人物检索第二轮统一筛选

P2 原则：
- 有独立人格 + 多卷重复出现 + 会影响后续剧情/关系/决策 → 上调为正式人物卡。
- 只负责一次性剧情功能 → 优先放时间线或地点事件，不单独占人物卡。
- 只有能力信息、没有持续人格戏份 → 优先能力/支族条目。

# 人物施工顺序

1. **先核对 P0 12 人的原著外貌锚点与人物身份。**
2. P0 一人一人精修完整角色条目，同时建立对应能力条目待办。
3. 每个人物施工时先冻结角色条目中的具体体型数值，再把复杂机制拆入能力条目。
4. 完成 P0 后统一做一次“主角团关系与时间线知识泄漏 QA”。
5. 再做 P1-A 新帝国核心常驻。
6. 再做 P1-B 神族。
7. 再做 P1-C 旧帝国/敌对线。
8. 再做 P1-D 后期/未来人物。
9. 最后审核 P2，决定哪些升格成正式人物卡。
10. 人物层冻结后统一检查能力层覆盖率与重复职责。
