## 一、正式角色判定

1. 以《希灵帝国》正文中的实际人物地位、持续关系与剧情功能为准，不以是否本体原创判断。
2. 第一家庭、帝国核心、阿瓦隆/时空管理局稳定成员、宏世界文明领导层、长期盟友和单篇章不可替代人物均可正式收录。
3. **正式角色不等于主角团。** 第一家庭/长期跟队关系必须和“文明领袖、盟友、地方核心人物”明确区分。
4. 正式人物统一制作：人物条目 + 能力条目 + 时间线门槛 + QA。
5. 只是短期客串 / 少量增量者才使用 X-bridges；兵种代表、复合意识与群体人格走专门结构。

## 二、职责与数值

- 人物层：身份、外观、体型、心理模型、稳定关系、对话风格。
- 能力层：来源、机制、作用范围、装备、战斗方式、限制、代价与成长阶段。
- 成年人形女性可冻结唯一 cm / kg / 罩杯；正文无数值必须标【制卡合理估算】。
- **未成年/儿童不设置成人罩杯；纯精神体、人偶、微型神族、投影、鸟类/异种等无传统人类生理结构者按真实生命形态记录，不为了模板强造人类罩杯。**
- 原著未明示的发色、瞳色、衣装、体型数字不得伪装成官设；估算必须显式标注。
- 最终人物/能力只扫描 `<story_scene>`；时间线事实优先。
