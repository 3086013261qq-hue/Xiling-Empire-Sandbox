# 《希灵帝国》人物层目录与收录规则 v1.3

> 状态：P0～P1-D 原高优先级人物 39/39 已完成；全文补漏后新增 P1-E / P1-F 正式角色层，进入补漏施工与 P2 二筛。
> 基线：设定层总审计完成后的 main；人物/能力母版按 P0 已冻结规则继续复用。

本目录决定“哪些人物需要进入《希灵帝国》世界书、优先级如何，以及角色条目 / 能力条目如何按咩咩制卡包·全栈职责分层”。

## 一、收录原则

1. **是否为正式角色，以《希灵帝国》正文中的实际长期地位为准，不以角色是否原创为准。**
2. 本体原创角色，以及来自外部作品但已经长期进入陈俊第一家庭、帝国常驻核心或长期行动队伍的角色，都可以制作正式完整人物卡。
3. 外部作品出身角色若只是短期客串 / 单世界盟友 / 有少量希灵侧新增状态，则不机械复制原作百科；只在必要时做轻量增量桥或依附时间线。
4. 已经长期常驻的外部角色不能因“原作来自别的作品”而降格成桥接说明；应制作完整人物条目 + 能力条目 + 时间线限域 + QA。
5. 人物卡不承担能力百科。人物条目写身份、外观、人格、关系、行为逻辑与能力概览；复杂能力另进能力层。
6. 任何后期人物、未来人物、隐藏身份、阵营变化、加入第一家庭 / 帝国的时间点都由时间线控制，不因人物条目存在而让早期角色提前知道。
7. 女性人物最终角色条目必须给出**唯一、具体的身高 cm / 体重 kg / 罩杯字母值**。原著明示优先；原著没有明确数值时，必须依据正文体型、年龄外观、比例与长期稳定描写给出【制卡合理估算】。最终注入条目不得使用“未知 / 待定 / 约某范围”代替必填数值，也不得把估算伪装成原著事实。
8. 原著存在多个冲突数值时，原著核对 / QA 文件完整保存冲突；最终角色条目选择一个最符合连续正文与稳定后期口径的**制卡冻结值**。
9. 同一人物若存在成长、变身、合体、重塑等导致外观变化：**变化后的外观结果写在角色条目里；变化的发动方式、机制、强度、限制和战斗效果写入能力条目。**
10. 同一存在的不同形态 / 人格优先判断是否需要“单条多状态”而不是机械拆成两个人物；真正独立人格、独立因果与长期独立行动者则分条处理。

## 二、咩咩全栈人物 / 能力职责边界

### 角色条目

最终角色条目继续使用固定 XML-like 格式：

```text
<【人物名】character>
名字:
性别:
印象:
发色:
发型:
瞳色:
身材:【身高cm,体重kg,体态描述】
胸部:【女性罩杯；男性胸肌/平坦度】
上衣:
下装:
配饰:
鞋子:

心理模型:
- Trauma:
- Defense:
- Trigger:
- Need:

对话范例:
“”
“”
“”
</【人物名】character>
```

角色条目负责：
- 正式姓名、性别、稳定身份与当前阵营；
- 发色、发型、瞳色、具体身高、具体体重、具体罩杯 / 胸部状态；
- 常态服装与标志性配饰；
- 若存在明确外观变化，在对应字段内用简洁状态标记记录**变化后的结果**；
- 人格、心理模型、稳定关系与对话风格；
- 只保留能力名称 / 一句话概览，不写完整机制百科。

### 能力条目

能力条目独立承担：
- 能力名称、来源、触发条件、发动方式；
- 机制、作用范围、强度、限制、消耗、反制与成长阶段；
- 战斗装备、特殊形态、荣耀形态、合体、变身等实现逻辑；
- 若能力会改变外貌，只说明“触发角色条目中的某状态”，不重复整套身材和服装描写。

一句话边界：**角色条目回答“她现在看起来是什么样、是什么人”；能力条目回答“她为什么能做到、怎样做到、能做到什么程度”。**

最终角色触发仍只扫描：`<story_scene>`。

# X｜外部作品人物的处理规则

不再使用“外部作品人物一律不做完整人物卡”的旧规则。

分为两类：

### A. 已长期进入第一家庭 / 帝国核心
→ **正式角色。**
进入 P1-F 或后续正式人物层，完整制作人物 + 能力 + QA。

### B. 只是高频盟友 / 短期常驻 / 少量希灵侧新增状态
→ 继续使用 `worldbook/characters/X-bridges/` 轻量桥，或依附时间线 / 阵营条目。

当前仍处于二筛 / 桥接层的典型角色：八云紫、御坂美琴、远坂凛、吉安娜、希尔瓦娜斯等。
