# 《希灵帝国》人物层目录与收录规则 v1.0

> 状态：人物目录骨架已建立；尚未开始逐人正文施工。
> 基线：设定层总审计完成后的 main。

本目录只决定“哪些人物需要进入《希灵帝国》本体世界书，以及优先级如何”。
具体外貌、能力、心理模型、服装、对话范例、触发 regex 与时间线知识边界，统一留到后续逐人精修时再依据小说全文核对。

## 一、收录原则

1. **只收《希灵帝国》本体原创人物与必须由本体世界书维护的身份变化。**
2. 外部作品人物不制作完整人物卡；其原作外貌、性格、能力、关系与原作历史交给咩咩预设同人搜索恢复。
3. 外部作品人物在《希灵帝国》中新增的帝国身份、特殊改造、当前阵营或重大剧情变化，只在必要时写“希灵侧增量状态”，不复制外部原作人物百科。
4. 人物卡不承担能力百科。人物条目写身份、外观、人格、关系、行为逻辑与能力概览；复杂能力另进能力层。
5. 任何后期人物、未来人物、隐藏身份与阵营变化都由时间线控制，不因人物条目存在而让早期角色提前知道。
6. 女性人物继续遵循制卡规则：逐人核对身高、体重、罩杯、发色、发型、瞳色、服装；小说没有明确数值时不得伪造“官方数据”，需要区分原文明示与制卡估算。
7. 同一存在的不同形态/人格优先判断是否需要“单条多形态”而不是机械拆成两个人物；真正独立人格、独立因果与长期独立行动者则分条处理。

- **艾莎莉**｜同上
- **阿尔忒弥斯**｜如神界—帝国通道、生命神殿剧情需要独立触发，则上调
- 其他只在单卷或单世界短期出现的本体原创人物：待人物检索第二轮统一筛选

P2 原则：
- 有独立人格 + 多卷重复出现 + 会影响后续剧情/关系/决策 → 上调为正式人物卡。
- 只负责一次性剧情功能 → 优先放时间线或地点事件，不单独占人物卡。
- 只有能力信息、没有持续人格戏份 → 优先能力/支族条目。

# 人物施工顺序

下一聊天建议严格按以下顺序推进：

1. **先核对 P0 12 人的原著外貌锚点与人物身份。**
2. P0 一人一人精修完整人物卡，同时建立其能力待办清单，但暂不展开能力正文。
3. 完成 P0 后统一做一次“主角团关系与时间线知识泄漏 QA”。
4. 再做 P1-A 新帝国核心常驻。
5. 再做 P1-B 神族。
6. 再做 P1-C 旧帝国/敌对线。
7. 再做 P1-D 后期/未来人物。
8. 最后审核 P2，决定哪些升格成正式人物卡。
9. 人物层冻结后才进入能力层。
