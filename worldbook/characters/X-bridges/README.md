## 本目录只收什么

仅收同时满足以下特征的轻量增量角色：
- 一次或少数几次客串；
- 只产生少量《希灵帝国》侧新增状态；
- 没有稳定长期关系/职能，也不足以支撑完整心理模型和独立能力层；
