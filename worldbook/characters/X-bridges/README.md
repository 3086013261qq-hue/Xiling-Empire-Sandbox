# X-bridges｜外部作品人物的《希灵帝国》侧增量桥

> 本目录不复制外部原作人物百科。
>
> 仅记录角色进入《希灵帝国》后新增的：第一家庭关系、帝国身份 / 阵营、长期居住状态、希灵侧能力变化、装备改造、特殊军务与时间线节点。

## S级｜首批必须桥接

1. **水银灯**｜长期第一家庭成员 / 陈俊明确以“女儿、家长”关系相处 / 大量帝国侧新增状态
2. **毒岛冴子**｜原著明确“跟第一家庭呆了很长时间” / 长期跨世界行动成员
3. **佐天泪子**｜获得希灵侧特殊能力与身份变化 / 原作状态已不足以覆盖其后续现实
4. **御坂妹妹**｜帝国接管后的长期群体身份；以“御坂妹妹群体 + 御坂10031代表”桥接
5. **吉尔妹 / 女性吉尔伽美什**｜帝国附庸军语境 / 小泡泡长期贴身护卫与家庭关系
6. **八云蓝**｜长期第一家庭同行与生活关系 / 妖怪镇—家庭桥梁
7. **雪华绮晶**｜陈俊精神海长期居留等重大希灵侧新增状态

## 桥接条目职责

桥接条目回答：
- 她什么时候、因为什么进入陈俊 / 第一家庭 / 帝国关系网；
- 在《希灵帝国》中新增加了什么长期身份或关系；
- 是否获得新的身体、能力、装备、军务职位或居住状态；
- 当前时间线下哪些信息已经解锁。

桥接条目**不回答**：
- 外部原作的完整出生背景；
- 外部原作完整人物关系；
- 原作外貌百科；
- 原作能力树与原作剧情复述。

推荐轻量格式：

```text
<希灵侧增量:角色名>
当前关系:
长期状态:
帝国侧新增身份:
希灵侧能力/装备变化:
关键关系变化:
时间线门槛:
</希灵侧增量:角色名>
```

最终触发同样只扫描 `<story_scene>`，并优先使用“人物名 + 帝国 / 第一家庭 / 对应新增状态语义”组合，避免普通原作场景误注入《希灵帝国》后期状态。
