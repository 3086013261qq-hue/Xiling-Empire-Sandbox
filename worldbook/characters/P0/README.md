## 一、证据口径

- **【原著正文明示】**：小说正文直接写出，可作为最高优先级人物锚点。
- **【原著正文定性】**：正文明确给出“高挑、娇小、贫乳、成熟”等定性，但没有数值。
- **【原著正文存在冲突】**：正文不同位置存在不一致，不伪装成唯一官方值；后续人物卡应选择稳定口径并保留注记。
- **【原著附录明示】**：精校 TXT 末尾作者“人物资料卡无责任版”等附录直接写出；保留，但与正文分级。
- **【原著未明示】**：全文核对后没有可靠落锤的项目；不得凭动画、同人图、百科或印象补成官方设定。
- **【制卡合理估算】**：只在后续完整人物卡需要“身高 / 体重 / 罩杯”等强制字段、且原著确无数据时使用。本阶段不提前填写估算值。
- 同一角色的**基础外貌、能力发动状态、变身/合体形态、后期改造**必须分开，不把状态性描写写成日常基础外貌。
- 后期真相只允许人物源码留档；是否能被角色知道、是否已成为现实状态，继续由时间线控制。

## 01｜陈俊

- **正式姓名 / 常用称呼**

- **身份与阵营**

  - 很早成为希灵帝国皇帝，后续为新帝国最高核心。

- **发色 / 发型 / 瞳色**
  - 【原著未明示】没有找到足够可靠、可作为固定人物锚点的基础发色、发型、瞳色描写。
  - 后续不得把常见同人形象反写为原著事实。
- **身高线索**
  - 【原著未明示】未找到稳定数值。
- **体型线索**
  - 前期是普通少年体态；很早经历希灵技术强化，后续身体强度变化属于能力/状态层，而不是“天生外貌”。

  - 【原著未明示】无必须常驻的个人配饰。
- **外貌随剧情变化**
  - 核心变化集中在身体强化与后期高阶生命状态；应写入能力层/时间线，不把后期状态倒灌给开篇陈俊。
- **关键人格特征**
  - 自嘲、随和、吐槽密集，早期以“普通人”心态面对异常世界。
  - 家庭感极强，保护欲和责任感强；随着帝国重建逐渐形成稳定的领袖担当，但日常人格没有变成传统威严皇帝。

- **核心关系**
  - 陈倩：无血缘的姐姐、最早的家庭核心。
  - 许浅浅：青梅竹马，后续恋人。
  - 珊多拉：恋人、帝国共同核心。
  - 潘多拉 / 维斯卡：以妹妹关系纳入家庭。
  - 泡泡 / 小泡泡：皇帝—主机关系之外形成强家庭关系；小泡泡将其视为父亲/监护人。
  - 阿赖耶：君主与使徒，同时具有“君主哥哥”式亲密家人关系。

- **能力名称与能力层待办**
  - 精神干涉 / 精神指令。
  - 皇帝权限、精神网络与使徒指挥。
  - 身体强化、后续虚空相关生命状态与能力。
  - 上述全部只在能力层按时间阶段拆解，不在人物卡正文展开机制百科。
- **后期知识 / 时间线限域**

  - 源意志、虚空结构、后期跨阵营真相。

  - 新帝国后期的完整权限、技术与政治地位。
- **最终制卡数值状态**
