> 编号承接 P1-E 的 40～44，本组从 45 起继续。

## 收录规则

1. 必须在《希灵帝国》正文中形成长期常驻，而非一次性客串或短期来访。
2. 必须拥有稳定独立人格、长期关系网，以及足够多的《希灵帝国》侧新增经历。
3. 正式角色统一制作：完整人物条目 + 独立能力条目 + 时间线限域 + QA。
4. 外部原作只作为角色前史来源；最终人物条目必须以《希灵帝国》当前现实状态为核心，不把角色降格成“桥接说明”。
5. 原作外貌 / 性格 / 基础能力若《希灵帝国》正文已有稳定描写，以正文为主要锚点；需要补足的原作固有信息不得和《希灵帝国》后续变化冲突。
6. 后期获得的新身份、能力、装备、身体状态和家庭关系必须写入正式角色 / 能力条目，并继续服从时间线门槛。
