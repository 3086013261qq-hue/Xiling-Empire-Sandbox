## 一、筛选原则

1. **出现次数只作为检索信号，不作为入选票。** 必须同时看首次/末次出场跨度、独立人格、跨篇章持续关系、后续剧情功能与世界书触发价值。
2. **外部作品出身不降级。** 在《希灵帝国》正文里已经形成稳定身份、长期关系、帝国/阿瓦隆/时空管理局编制，或持续参与宏世界事务者，均可成为正式角色。
3. **正式角色不等于陈俊直属军官。** 第一家庭成员、长期朋友、帝国眷族文明领袖、稳定盟友、世界守护者、重要宗教/民政负责人都可以进入正式人物层。
4. 单一大篇章人物若人物塑造完整、独立因果强、对该篇章不可替代，也可做正式人物卡；但与跨卷常驻人物分层施工。
5. 普通兵种代表、复合意识、群体人格继续走专门结构，不机械套普通人物卡。
