## 一、为什么分成13卷

主线正文编号到 **第1613章《那道光（结局）》**。若只按8卷切分，多个大型世界线、战争线和帝国史揭露会被塞进同一卷，后续生成时间线时容易出现单卷 token 过大、绿灯触发跨度过宽、晚期信息提前污染前段剧情的问题。

因此冻结为 **13卷**：每卷尽量以一次明显世界切换、主线战争收束、回家/善后或高位设定揭露为边界，平均约100～160章，便于后续按卷生产时间线并在必要时继续拆为上/下卷而不破坏连续性。

## 三、番外与2.0版的处理规则

### 1. 番外《苏醒1～3》
源文件在主线结局之后统一收录，但它们的叙事时间并不位于“第1613章之后”。后续制作时间线时必须依据内部事件锚点，**插回对应历史阶段**，禁止因为文件排版位置而把番外机械放到第十三卷末尾。

### 2. “作品相关”资料
角色资料卡、战争载具说明等属于作者补充材料，可用于核对设定/外观/能力来源，但**不作为发生事件写进时间线**。

### 3. 2.0版前45章
源文件在“2.0版”标题下收录第1～45章修订稿，并明确备注其为修改版、可能与后文衔接不完整。

因此冻结规则：
- 主时间线的连续章节骨架仍使用正文 **1～1613**；
- 2.0版 **不是第14卷，也不是结局后的新事件**；
- 对正文1～45章做时间线时，可将2.0作为“早期修订补充证据层”核对细节；
- 若2.0细节与主线后续连续事实冲突，以能够贯通1～1613的主线连续性优先；不得为了采用2.0局部改写而破坏后续时间线。

## 四、后续每卷时间线生产规则

1. 格式继续使用：`YYYY年MM月DD日 + 卷内 A/B/C 编号`。
2. 保留原著章名/事件原题，不另造看似官方的标题。
3. 连续事件按真实时间推进，跨日则次日；原著未给精确日期时不得伪造官方日期，先通过正文季节、星期、节日、相对时长等证据推导并在QA注明；无法唯一确定月日时，可补造“制卡锚定日期”，但必须在QA明确其工程推定性质。
4. 一卷内只写该卷已经发生/已经揭露的事实；后卷真相不得提前倒灌。
5. 人物/能力静态条目服从时间线当前状态。
6. 若某卷生产后 token 明显过大，允许在不改变13卷母结构的前提下拆为“第X卷（上）/（下）”；上下时间与剧情必须连续，但每个独立 `<world_timeline>` 块均重新从事件A开始，并各自以“沙盒模式”结束。
