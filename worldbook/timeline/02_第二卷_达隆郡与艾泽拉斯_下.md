# 第二卷｜达隆郡与艾泽拉斯（下）

范围：原著主线第190章《提瑞斯法林地》～第280章《回家喽》。

母卷：第二卷｜达隆郡与艾泽拉斯（第119～280章）。本文件是独立 `<world_timeline>` 块，因此事件编号重新从A开始；这只是显示层拆分，不新增卷序，不改变13卷母结构。

日期口径：
- 所有正式事件均使用确定的 `YYYY年MM月DD日`；
- 第190～274章主体使用“艾泽拉斯当地制卡锚定日”，严格服从正文“三天 / 两天 / 几天 / 将近半个月 / 三天多 / 第二天凌晨 / 战后三天 / 至少三天 / 前前后后十几天”等相对时长；
- 第274章末至第275章开场切回地球外层时钟；第279章明确“距出发那天才过了一星期”，因此由2011年09月23日地球出发锚闭环到2011年09月30日返抵地球；
- 第275～280章锚定2011年10月01日；第276章明确“今天是周末”，而2011年10月01日为周六，与该闭环一致；
- 艾泽拉斯当地日期与地球公历是两套坐标，数值不得直接比较或换算；
- 原著未给唯一月日的节点均为工程推定，证据与冲突记录于 `qa/028_第二卷时间锚点与连续日核验_v1.0.md`。
