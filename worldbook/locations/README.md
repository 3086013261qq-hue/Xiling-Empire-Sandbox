## 一、地点层目标

地点层只收录能够独立支撑场景生成、反复回访、承载稳定势力/规则，或需要随时间线发生所有权/状态变化的地点。

不执行“原著出现过一个地名就全部拆条目”的机械收录。一次性战场、无专名山洞、临时营地、普通街巷等，默认留在对应父地点正文或时间线事件中，避免世界书 token 膨胀。

地点条目必须：

1. 以原著实际名称为准，不自行补造官方地名；
2. 原著没有专名但确有必要单列时，必须显式标注 `【描述性目录名，原著无专名】`；
3. 地点的开放、毁坏、重建、迁移、归属与人员状态服从当前时间线，不得把后期状态倒灌到前期；
4. 设定、人物、能力和时间线只做交叉引用，不在地点层重写冻结内容；
5. 世界、星球、城市、设施、长期移动载具都可以成为地点条目，只要具有独立稳定的场景身份。

## 五、默认不独立成条目的内容

以下类别若没有稳定专名和重复场景身份，默认不拆：

- 一次性山洞、峡谷、荒原、战壕、临时营地；

- 泛称“研究所 / 基地 / 皇宫 / 城镇 / 战场”但原著没有稳定独立身份者；
- 仅为路线节点、没有生态/社会/规则信息的中转地；
- 可以自然并入父地点而无需单独关键词触发的设施。
