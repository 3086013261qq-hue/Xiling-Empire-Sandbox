## 一、地点层目标

地点层只收录能够独立支撑场景生成、反复回访、承载稳定势力/规则，或需要随时间线发生所有权/状态变化的地点。

不执行“原著出现过一个地名就全部拆条目”的机械收录。一次性战场、无专名山洞、临时营地、普通街巷，以及本质上属于机构/组织而缺乏独立物理场景身份的候选，均不得为了凑数强行做成地点。

## 二、正式地点格式

严格使用《咩咩制卡·全栈》原生地点正文：

```text
<地点:正式名称>
介绍:地点客观描述
</地点:正式名称>
```

规则：

1. 一个可复用的大地点默认对应一个正式地点条目，不把空间、交通、居民、功能、历史阶段拆成多张小卡；
2. 同一叙事地点若随时间发生迁居、重建或物理形态变化，可在同一 `介绍:` 中按原著先后说明，但运行时必须服从当前正式时间线；
3. 子区域只有在可独立反复支撑场景、需要独立 `当前位置:` 触发时才晋升独立地点；
4. 原著没有专名但确需单列时，必须显式标注 `【描述性目录名，原著无专名】`；
5. 地点正文采用客观场景描述，不绑定必然剧情，不复制人物/能力/时间线正文；
6. 最终装配时地点属于 order 100~1 的触发型 after_char 条目，主要通过 `<status>` 中 `当前位置:` 精确触发；
7. 原著证据、章节统计、层级争议和格式QA留在 `qa/**`。

格式基线：`worldbook/locations/LOCATION_TEMPLATE.md`  
格式校正QA：`qa/055_地点层全栈原生格式校正与影子城样本复核_v1.0.md`

### 已核定的重要层级与口径

- `影子城`：首府核心城市与主要公共生活区。
- `影子空间`：首府主要父级人工世界及军政承载空间。
- `帝国首府`：成熟期由核心城市、母星、影子空间、挂载区及交通/军政设施组成的复合首府体系。
- `首府星`：具体星球概念；后期新帝国语境下指母星盖亚。
- `首府世界`：按原著具体章节语境读取，不与“首府星”机械合并。
- `遗忘花园 != 天使之城`：天使之城完整释放后位于遗忘花园约17公里高空，两者共用部分数据链但为空间独立设施。
- `深潜港/深潜试验港`：同类高危实验设施口径，不是固定永恒坐标；可随试验宇宙和深渊之门迁移重建。
- `星域神界 != 休伦神界`：两大神系独立核心世界，不能互套建筑与环境描写。
- `深渊区 != 深渊内部`：前者为堕落使徒控制的大量世界组成的虚空尺度战略区域。
- `宁静核心 != 宁静地带`：前者是广域宁静区信息纠缠中心的特殊架桥宇宙。
- `陈俊家`：叙事上稳定的第一家庭住宅标签；物理房屋存在迁居阶段，中后期“陈家大宅”不能倒灌到早期住宅。

## 六、默认不独立成条目的内容

- 一次性山洞、峡谷、荒原、战壕、临时营地；
- 单场战斗才出现的舰内舱室或阵地；
- 泛称研究所/基地/皇宫/城镇/战场但没有稳定独立身份者；
- 仅为路线节点、没有独立空间与社会规则的中转地；
- 能自然并入父地点、无需单独 `当前位置:` 触发的内部设施；
- 本质为行政机构、组织、职位或概念，且没有独立稳定物理空间描写者。
