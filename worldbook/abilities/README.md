禁止技能面板、等级表、数值伤害表和游戏化冷却栏。

## 二、职责边界

- 角色层：人物是谁、长什么样、稳定身份/关系/心理和变形后的外观结果。
- 能力层：来源、发动、机制、范围、装备、战斗方式、限制、代价、成长与反制。
- 同一事实不在两层完整重复。

## 三、触发与时间线

1. 能力最终只扫描 `<story_scene>`。
2. 普通日常只提人物名时不注入整套能力；最终触发组合“人物名 + 能力/战斗/对应状态语义”。
3. 后期能力可存在源码，但必须由时间线解锁后才能成为当前现实。
4. 时间线事实优先于静态源码。
5. 人物能力不得重定义已冻结的虚空、深渊、资讯、精神网络、权限、神族本源等全局机制。
6. P1-D 未来公主、P1-E 后期身份、P1-F 加入第一家庭/帝国后的变化均属于高泄漏风险信息。
