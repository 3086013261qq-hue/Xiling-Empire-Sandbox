## 二、职责边界

- 角色层：人物是谁、外观、稳定身份/关系/心理与形态结果。
- 能力层：来源、发动、机制、范围、装备、战斗方式、限制、代价与成长。
- 同一事实不在两层完整重复。

## 三、触发与时间线

1. 能力最终只扫描 `<story_scene>`。
2. 普通日常只提人物名时不注入整套能力；最终触发组合“人物名 + 能力/战斗/对应状态语义”。
3. 后期能力由时间线解锁后才能成为当前现实。
4. 时间线事实优先于静态源码。
5. 不得重定义已冻结的虚空、深渊、资讯、精神网络、权限、神族本源等全局机制。
6. 外部作品角色只保留《希灵帝国》正文实际实装与当前世界需要的能力，不搬完整外部技能表。
