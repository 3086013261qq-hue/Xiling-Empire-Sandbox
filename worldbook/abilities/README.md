# 《希灵帝国》能力层装配与职责总则

> 状态：能力层母版已冻结；P0～P1-D 高优先级人物对应能力条目 **39/39 完成**，进入 P2 候选筛选。

本目录保存《希灵帝国》本体人物的独立能力绿灯源码。人物是谁、长什么样、人格和关系如何，归 `worldbook/characters/`；能力如何发动、作用、限制、成长和被反制，归本目录。

## 一、唯一正式母版

严格复用咩咩制卡·全栈能力绿灯格式：

```text
<核心设定:角色名·能力>
能力定位:...
核心能力:
- ...
法宝与武器:
- ...
战斗特点:...
限制与代价:
- ...
</核心设定:角色名·能力>
```

不得自行增加技能面板、等级表、数值伤害表或游戏化冷却栏。

## 二、与角色条目的职责边界

- 角色条目负责：姓名、性别、印象、外貌、具体身高 / 体重 / 罩杯、服装、人格、心理模型、对话风格，以及变身后“看起来变成什么样”。
- 能力条目负责：能力来源、触发、机制、作用对象、强度边界、战斗方式、装备、限制、代价、反制、成长阶段，以及“为什么能变成那样”。
- 同一事实不在两层完整重复；角色层只保留识别结果，能力层才展开机制。

## 三、时间线与触发

1. 能力条目最终只扫描 `<story_scene>`。
2. 普通日常仅提到人物姓名时，不应自动注入整套能力百科；最终 regex 应组合人物名与能力、战斗、变身或对应状态语义。
3. 后期能力可以存在于源码，但只有时间线确认已经解锁后才能成为当前人物可知、可用的现实能力。
4. 时间线事实优先于静态能力源码；不得因完整能力条目存在而让早期人物提前知道后期真相。
5. 能力调用必须服从已冻结设定层；不得借人物能力重新定义资讯、虚空、深渊、精神网络、权限、神族本源等通用世界机制。
6. P1-D 未来人物属于最高泄漏风险层：晓雪 / 晓浅 / 晓珊的未来身份、父母关系、虚空大灾变后信息、未来公主同盟默认均不可提前注入。

## 四、数值与外观变化

能力层不重复填写身高、体重、罩杯等人物数据。若能力导致这些数据变化：

- 变化后的具体外观与数字写回对应角色条目；
- 本层只解释变化条件、机制、持续方式与限制；
- 能量化、虚空化等使传统质量概念失效的状态，不强行伪造公斤数。
