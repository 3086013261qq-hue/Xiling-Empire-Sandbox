# 《希灵帝国》设定层装配与职责总则

本目录保存《希灵帝国》角色卡的纯设定层源码。当前结构由 9 条蓝灯全局规则与 59 条绿灯场景展开组成；蓝灯负责跨时代成立的世界底层事实，绿灯负责在具体语义出现时补充机制细节。

## 一、蓝灯与绿灯

- **蓝灯只保留不可缺失的全局不变量。** 不承担具体人物、具体装备、具体地点、某卷当前状态或后期剧情结果。
- **绿灯只展开一个明确问题。** 同一事实如果已经由另一组承担，当前条目只保留建立边界所需的最少说明，不再次完整定义。
- **蓝灯事实全局成立，不等于所有角色全局知晓。** 谁在什么时间点知道哪些真相，由时间线、人物知识与运行规则控制。
- **绿灯触发必须限于场景语义。** 最终装配时优先扫描 `<story_scene>`；地点机制可按需要读取 `<status>` 中的当前地点。不要仅凭聊天历史里曾经出现过一个名词长期常亮。

## 二、核心术语口径

- **资讯 / 信息：** “资讯”用于描述现实底层、世界结构和工程化对象；小说中的固定复合术语继续保留“信息”，例如“信息纠缠点”“信息映射”“信息表征”“信息偏移量”。二者不是两套不同物理体系。
- **世界屏障：** 秩序区域与虚空之间的临界接口，不是包裹宇宙的物理壳。
- **秩序场：** 在虚空中维持局部自洽秩序的环境，不等同于普通能量护盾。
- **世界之心：** 信息纠缠点的现实承载体，不是主动管理员。
- **世界管理系统：** 能够直接接入并控制信息纠缠点的本源级管理接口。
- **世界仲裁机关：** 希灵世界级工程设施，主要通过既有法则体系修正参数；不能与世界管理系统、本源接口混写。
- **深渊本体：** 非秩序污染本身；被感染个体、深渊生物、堕落文明均不能自动等同于深渊整体意志。
- **精神网络：** 希灵使徒的种族级连接与整体意志基础，不等同于权限体系，也不是蜂巢主脑。
- **权限：** 系统访问与指令资格；与军衔、战斗力、知识、技术能力和网络地位相关但不等同。
- **科技侧 / 神秘侧：** 两种研究和工程路径，不是两个互不兼容的宇宙体系；成熟希灵工程可在资讯层实现兼容与混合。

## 四、触发防碰撞原则

1. **优先使用专名或复合语义，不使用过宽单词。** 例如“世界再激活”优于“世界”，“个体实体映射”优于“分身”，“深渊之门”优于“门”。
2. **通用机制与具体应用只亮主责条目。** “秩序场在虚空里维持 1+1=2”由 01-02 负责；讨论数学率作为通用技术时才由 09-05 负责。
3. **本源机制与神族应用分开。** “信息纠缠点是什么”触发 BLUE03；“神族世界管理系统接管信息纠缠点”触发 BLUE08。
4. **世界再激活与世界仲裁机关分开。** 前者触发 03-06；讨论仲裁机关作为设施、权限和工程层级时触发 09-07。
5. **文明心理与网络纪律分开。** 流亡、扩张、深渊使命触发 06-07；精神网络同步、命令执行与纪律触发 07-02。
6. **支族形成规则不以具体支族名常亮。** 装甲蝎、渡鸦、人工天使等具体名称以后优先触发对应人物/能力/支族条目。
7. **普通词不得造成极端机制误触发。** “分身”“预知”“安全区”“深潜”“恢复理智”等必须与对应世界观语义组合后才能进入最终 regex。

## 五、时间线与知识隔离

设定层保存的是完整世界真相，不承担“角色此刻知道多少”的限制。后续装配必须让时间线控制以下内容的可知性与现实状态：旧帝国历史、休伦神族、源意志、世界本源理论、人工世界之心、后期深渊研究成果、后期技术与任何尚未发生的剧情结果。

因此，不能因为某条蓝灯常驻就让早期角色直接说出后期理论；蓝灯负责保证叙事世界不会违背最终底层规律，人物发言和决策仍应受当前时代知识约束。

## 六、外部作品与同人搜索

外部原作角色、地点、力量体系、原作历史与当前剧情状态不重复写入《希灵帝国》本体世界书。进入可识别的外部作品世界时，由咩咩预设的同人搜索恢复外部原作资料；本世界书只提供希灵侧人物、技术、力量、事件与新增变量。

运行时冲突优先级保持：**用户明确设定 > 当前已发生的真实剧情与时间线 > 外部原作检索资料 > 文化作品旧投影。** 这一条属于装配/运行规则，不改写小说内部的世界干涉机制。
