# BLUE07 绿灯组目录｜权限、精神网络与皇帝原则

本目录展开 BLUE07《希灵帝国权限体系、精神网络与皇帝原则》。本组只负责希灵文明内部的精神网络、权限、皇帝与指令秩序，不展开具体人物能力、具体武器、科技细节或剧情事件。

## 绿灯
- 07-01｜精神网络、个体人格与整体意志
- 07-02｜网络同步、共同目标与帝国纪律
- 07-03｜权限、军衔、战斗力与知识边界
- 07-04｜NT皇帝权限与最高指令节点
- 07-05｜天区、皇帝与皇权议会的历史结构
- 07-06｜精神网络具象化个体与权限边界
- 07-07｜帝国设施、协议、授权与指令执行

## 组内边界
- 07-01 定义精神网络与人格是否独立。
- 07-02 解释网络为什么能形成高度同步、共同目标与纪律，但不把它写成思维控制。
- 07-03 分离权限、军衔、战力、技术能力、知识与网络地位。
- 07-04 只处理 NT 级皇帝权限的性质与最高决策职责。
- 07-05 只处理旧帝国天区—皇帝—皇权议会这一历史治理结构及其时代边界。
- 07-06 专门处理精神网络具象化个体，防止“网络化身＝超级皇帝”。
- 07-07 解释帝国设施、协议、武装与指挥链如何实际执行权限。

## 不在本组展开
- 希灵使徒起源、支族进化、非定型生命：BLUE06。
- 深渊污染精神网络、污染传播：BLUE04。
- 帝国科技、武器、主机、通讯设备具体机制：BLUE09 或装备/能力层。
- 具体皇帝、将军、主机、网络化身角色：人物层。
- 各时代谁知道哪些权限历史：时间线/运行规则层。
