# BLUE06 绿灯组｜希灵使徒起源、生命本质与种族使命

上位蓝灯：`worldbook/settings/blue-global/006_希灵使徒起源生命本质与种族使命.md`

本组只负责希灵使徒的种族起源、生命基础、支族形成、文明继承与深渊使命；精神网络、权限、皇帝结构归 BLUE07，具体科技设备与武器归 BLUE09/能力装备层。

## 条目

- 06-01｜创造者、逃亡与使徒诞生
  - 触发语义：创造者、太古文明、故乡、逃亡、最早使徒、起源史
- 06-02｜原体、初始设计与缺陷
  - 触发语义：原体、第一代使徒、初始序列、古老使徒、原始结构
- 06-03｜非定型生命、身体定制与基础单元
  - 触发语义：非定型生命、半能量构装体、身体定制、生命基础、实体/能量体
- 06-04｜支族分化、全族晋升与主动进化
  - 触发语义：支族、装甲蝎、渡鸦、人工天使、战争机器、晋升、全族进化
- 06-05｜适应能力、战争进化与能力边界
  - 触发语义：适应、进化、自我改造、新威胁、强化、生命重构
- 06-06｜文明继承、“希灵人”与“希灵使徒”身份
  - 触发语义：希灵人、希灵使徒、文明继承、创造者遗产、文化知识
- 06-07｜深渊使命、扩张倾向与文明心理
  - 触发语义：对抗深渊、使命、扩张、战争倾向、故乡毁灭、文明心理

## 边界

- 不展开精神网络的正常结构、高层集体意念、权限和皇帝节点：BLUE07。
- 不展开具体武器、幽能模块、舰船、法则设备：BLUE09/能力装备层。
- 不把后期“第三神族”等具体晋升结果写成所有时间段的既成事实：时间线决定当前阶段。
- 不把创造者早期历史中的学术猜测写成确定事实。
- 不把“强适应性”解释为即时万能进化或自动获得未来能力。
