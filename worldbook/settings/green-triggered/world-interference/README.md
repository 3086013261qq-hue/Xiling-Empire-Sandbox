# BLUE02｜世界干涉・资讯投影・幻想世界｜绿灯拆分目录

上位蓝灯：`worldbook/settings/blue-global/002_世界干涉资讯投影与幻想世界.md`

本组只展开世界干涉如何表现、为什么会失真和错位、历史改变后投影如何衰减，以及少数极端投影现象。不重复解释世界本源、世界之心、资讯零点等 BLUE03 内容，也不写具体同人作品的运行检索规则。

## 02-01｜世界干涉与文化作品再现
负责：跨世界资讯如何经过折射、变形与因果重组，在另一世界表现为小说、游戏、神话、梦境、灵感等文化产物。
典型触发语义：世界干涉、幻想世界、作品原型、小说原型、游戏原型、神话映照、灵感来源。

## 02-02｜投影失真、时间错位与提前映照
负责：资讯投影为什么不是镜像复制；资讯干涉、时间轴错位、虚空畸变与因果乱码如何造成细节偏差、顺序偏差、延迟或提前出现。
典型触发语义：投影失真、时间错位、提前映照、未来投影、世界干涉预知、因果乱码。

## 02-03｜历史分叉、惯性余波与投影中断
负责：源世界真实历史被改变后，旧投影为何仍可能短暂沿原路线继续，并最终因世界偏移而失真、中断。
典型触发语义：历史改变、剧情偏离、惯性余波、原本命运、旧投影继续、投影中断。

## 02-04｜资讯投影集中与个体实体映射
负责：极端情况下，原本分散的跨世界资讯集中到单一个体后，如何形成具备现实效力的资讯投影个体，以及投影与本体之间可能存在的联系。
典型触发语义：个体实体映射、资讯投影个体、资讯实体、跨世界同位个体、投影集中、信息形成的实体。

## 02-05｜极限世界干涉、局部实体投影与法则污染
负责：世界干涉被放大到极端时，局部环境、空间或世界结构如何实体投射到另一世界，以及不同世界法则接触时可能产生的异常与污染。
典型触发语义：局部世界投影、实体化投影、世界重叠、时空畸点、法则污染、世界结构投射。

## 边界
- 文化作品只是资讯再现，不等于命运剧本；这一原则由上位蓝灯维持。
- 同人搜索、资料检索、用户设定优先级属于运行规则层，不写入本组。
- 世界本源、世界之心、资讯纠缠点与资讯零点归 BLUE03。
- 人工制造实体资讯、法则兵器与具体设备性能归 BLUE09 及能力/装备层；本组只描述世界干涉现象本身。
