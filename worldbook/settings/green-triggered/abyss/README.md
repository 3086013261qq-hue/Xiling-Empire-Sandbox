# BLUE04｜深渊・非秩序・归零｜绿灯拆分目录

上位蓝灯：`worldbook/settings/blue-global/004_深渊非秩序与归零.md`

本组只展开深渊进入有序世界后的具体污染、传播、防护、净化与世界级后果，不重复 BLUE05 的宏观秩序—深渊长期平衡，也不展开具体深渊兵器、深潜船型号或人物专属能力。

## 04-01｜深渊污染的可见形态与感染阶段
负责：主物质世界中的可见形态、早期/后期症状、现实异常与阶段升级。
典型触发语义：深渊污染、二维平面、黑色花纹、情绪狂躁、设备异常、物理常数紊乱、空间崩塌、感染阶段。

## 04-02｜资讯载体、精神网络与潜伏传播
负责：深渊如何借助精神网络、通讯链路、信息载体传播，潜伏期与“断线不等于清除”。
典型触发语义：精神网络感染、通讯污染、信息污染、潜伏深渊、网络变异、污染传播。

## 04-03｜被感染个体、深渊生物与深渊本体
负责：被感染生命、具有思维能力的深渊生物与“深渊本体”之间的概念边界。
典型触发语义：堕落个体、深渊生物、疯狂化、深渊意志、理性行为、深渊本体。

## 04-04｜防护系统污染、恶性循环与隔离
负责：深渊为何能污染防护系统本身、冗余为何会失效、隔离带/断网/设施下线的意义与边界。
典型触发语义：防护失效、污染护盾、冗余系统、隔离区、安全区、断网、封锁污染。

## 04-05｜抗性、自我净化与逆向净化边界
负责：个体抗性、自我净化、逆向净化可行范围，以及“完全感染”与高强度个体的净化上限。
典型触发语义：深渊抗性、自我净化、逆向净化、恢复理智、感染度、完全疯狂化。

## 04-06｜深渊之门、泄露与污染束缚
负责：深渊之门作为泄露接口、二维污染在主物质世界中的扩散，以及束缚/诱导污染实体化时的危险。
典型触发语义：深渊之门、深渊泄露、二维影子、污染束缚、污染炸弹、深潜、门体失稳。

## 04-07｜世界级感染、秩序崩溃与归零
负责：从局部污染上升到世界结构破坏的终末过程，以及“毁灭”与“归零”的区别。
典型触发语义：世界级感染、现实崩坏、法则失效、秩序崩溃、空间坍塌、归零、世界湮灭。

## 边界
- 深渊与多元宇宙长期动态平衡、为何无法永久根除：BLUE05。
- 希灵使徒作为种族的起源与使命：BLUE06。
- 帝国精神网络正常结构与权限体系：BLUE07；本组只描述其被深渊污染时的异常。
- 具体深渊武器、诱捕者型号、深潜船结构、专属净化能力：BLUE09 或能力/装备/人物层。
- 角色在不同时间点知道多少深渊真相：由时间线与运行规则控制，不在本组正文中提前泄漏。
