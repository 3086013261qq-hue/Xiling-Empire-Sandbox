# BLUE03｜资讯・法则与世界本源｜绿灯拆分目录

上位蓝灯：`worldbook/settings/blue-global/003_资讯法则与世界本源.md`

本组只展开世界诞生、信息纠缠点、世界之心、世界管理层级、法则重赋值与资讯实体化等具体机制，不重复 BLUE02 的跨世界资讯投影，也不承担 BLUE08 的神族组织设定或 BLUE09 的具体兵器目录。

## 03-01｜资讯总爆发、信息纠缠点与世界呼吸
负责：世界由“零”进入“有内容”时的资讯总爆发、信息纠缠点如何形成，以及世界从诞生到归零的一次性“呼吸”。
典型触发语义：资讯总爆发、信息纠缠点、世界诞生、创世纪、世界呼吸、世界末日、信息源点。

## 03-02｜世界之心、凭依载体与信息跳转
负责：信息纠缠点实体化或依附现实载体后的世界之心、寄主变化、跳转规律与载体性质。
典型触发语义：世界之心、寄主、凭依物、载体、世界之心转移、信息跳转、世界核心。

## 03-03｜世界之心的作用边界、稳定性与失效条件
负责：世界之心能做什么、不能做什么；其对本世界的稳定作用、近乎不可直接销毁的性质，以及脱离所属世界后的效力边界。
典型触发语义：摧毁世界之心、保护世界之心、世界之心能力、世界之心失效、世界毁灭、世界墓碑。

## 03-04｜人工世界之心、超资讯体与平台技术
负责：人工制造或转接世界之心的高阶资讯工程、超资讯体的基本性质，以及这类技术为何属于平台级手段而不是万能终端能力。
典型触发语义：人工世界之心、超资讯、超资讯体、信息纠缠点转接、人工核心、旧帝国资讯技术。

## 03-05｜世界管理接口与本源控制层级
负责：直接控制信息纠缠点的世界管理方式，与只能借助既有法则修正宇宙参数的控制方式之间的层级差别。
典型触发语义：世界管理系统、信息纠缠点控制、本源控制、世界管理、宇宙参数、法则接口。

## 03-06｜法则参数修正、资讯零点与世界再激活
负责：法则级参数修改、资讯零点、世界低格与重新赋值、世界再激活及其小规模形式的基本逻辑。
典型触发语义：世界仲裁、资讯零点、负奇点、奇点爆发、世界再激活、热启动、法则重塑、宇宙格式化。

## 03-07｜资讯重组、实体化与工程边界
负责：“信息即真实”在工程层面的含义：如何通过读取、编码、重组世界信息形成具有现实效力的实体，以及这种能力所需的数据、能源、计算与法则条件。
典型触发语义：资讯实体化、信息重组、信息构成实体、镜像实体、世界信息片段、资讯工程。

## 边界

- 跨世界文化作品、幻想世界映照、历史分叉后的资讯投影归 BLUE02 及其绿灯。
- 神族为何能够从世界本源管理世界、星域与休伦等神族体系归 BLUE08 展开；本组只描述能力层级本身。
- 具体希灵武器、舰船、数学率武器、幽能装置等归 BLUE09 与装备/能力层；本组只描述支撑它们的世界级机制。
- 任何资讯层能力都必须依赖对应技术、权能、系统、能源与权限；“信息存在”本身不产生无条件改写现实的效果。
