# BLUE09 绿灯组目录｜希灵科技基本范式

本目录展开 BLUE09《希灵科技基本范式》。本组只负责希灵技术如何研究、分类、工程化和判断能力边界，不重复具体人物、具体战役、完整世界本源机制或虚空交通机制。

## 绿灯
- 09-01｜科技侧、神秘侧与两种研究路径
- 09-02｜资讯论统一与现实工程化
- 09-03｜希灵主机、混合型单位与跨侧基础设施
- 09-04｜幽能：高位能源、同化效应与工程介质
- 09-05｜数学率、规则环境与非物质层工程
- 09-06｜法则武器、资讯武器与作用层级判定
- 09-07｜世界级技术、仲裁机关与能力边界
- 09-08｜技术评价：条件、权限、规模与“强度”误区

## 组内边界
- 09-01 只解释科技侧和神秘侧的研究方法差异。
- 09-02 解释为什么两侧最终能以资讯论统一，但不把资讯写成许愿机制。
- 09-03 只负责主机与帝国基础设施的跨侧兼容。
- 09-04 只定义幽能作为高位能源/介质的工程特征，不把具体武器能力归给所有幽能设备。
- 09-05 专门处理数学率工程与规则环境，不重复 BLUE01 的虚空生存机制。
- 09-06 负责高阶武器如何按实际作用层级分类，不建立具体装备百科。
- 09-07 只说明世界仲裁等世界级工程所处层级及边界；世界再激活完整机制仍归 BLUE03。
- 09-08 提供判断技术能否实际生效的通用工程框架。

## 不在本组展开
- 世界/位面/虚空、秩序场、虚空引擎：BLUE01。
- 信息纠缠点、世界之心、世界再激活完整机制：BLUE03。
- 深渊感染技术系统的具体方式：BLUE04。
- 希灵使徒生命形态与进化：BLUE06。
- 权限体系和精神网络本身：BLUE07。
- 神族本源控制与神族文明：BLUE08。
- 星河主炮、恐怖镜像、幽能死星等具体装备/设施：后续能力与装备条目。
- 各时代掌握哪些技术、哪些角色知道哪些原理：时间线/运行规则层。
